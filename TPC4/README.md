# Resumo:
O trabalho de casa da quarta semana consistiu na implementação em Python de uma aplicação interativa para a manipulação de listas de números inteiros, estruturada através de um menu de opções.

A aplicação guarda uma lista numa variável interna e permite ao utilizador criar uma lista com números aleatórios entre 1 e 100 ou introduzir uma lista manualmente, sobrepondo qualquer lista existente. A partir dessa lista, é possível calcular a soma, a média, o maior e o menor elemento, verificar se os números estão ordenados por ordem crescente ou decrescente, e procurar um elemento específico (devolvendo a sua posição ou -1 caso não exista). Por fim, a opção de sair encerra o programa e exibe a lista guardada no momento.
